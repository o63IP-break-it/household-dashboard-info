# Privacy policy: Household Dashboard

Last updated: November 14, 2026

**Who uses it.** Household Dashboard is a personal app used only by the
members of one household. It is not offered to the public.

**What it accesses.** With your permission, it reads your Google Calendar
events and calendar list using the read-only scope
`https://www.googleapis.com/auth/calendar.readonly`. It cannot create,
change, or delete anything in your Google account.

**How the data is used.** Only to show your events on the household's
display.

**Where the data is stored.** Sign-in tokens and recently fetched events
are kept only on the household's own device. Nothing is sent to any
other server, and nothing is sold, shared, or used for advertising.

**Google API Services.** Use of information received from Google APIs
adheres to the Google API Services User Data Policy, including the
Limited Use requirements.

**Removing access.** You can revoke access at any time at
https://myaccount.google.com/permissions. Deleting the app's token file
on the device removes the stored sign-in.

**Contact.** Open an issue on this repository.
